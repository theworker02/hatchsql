# hatchsql

Hatch lightweight sql statistics from stdin samples.

**Site:** https://theworker02.github.io/hatchsql/

## Install / run

```bash
git clone https://github.com/theworker02/hatchsql.git
cd hatchsql
node src/cli.js
node --test
```
